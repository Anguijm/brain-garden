# Sonic the Hedgehog (Master System)

**Developer:** Ancient | **Publisher:** Sega | **Year:** 1991

---

## Introduction

This is the same game as the Game Gear Sonic — Ancient built one 8-bit Sonic and it shipped on both machines — but the Master System version is the better one to play, for a single reason: **the screen shows more.**

The Game Gear's display is 160x144. The Master System outputs 256x192. Same level layouts, same physics, but you can see hazards coming. Everything that makes the handheld version feel unfair is a consequence of the viewport, and this version fixes it by being on a television.

It is also a completely different game from the Genesis Sonic, sharing only a name and some zone titles.

---

## Controls

- **D-Pad:** Move, duck.
- **Button 1 / 2:** Jump.
- **No spin dash.** It does not exist in this game. Rolling is done by ducking while moving.

---

## What differs from the Genesis game

**Rings behave differently.** Take a hit and you keep **one** ring, not a scattered recoverable cloud. Damage effectively costs you everything, which makes the game far more cautious than its 16-bit counterpart.

**Chaos Emeralds are hidden in the levels**, not in special stages. One per zone, off the main path. All six changes the ending.

**The physics are slower and more deliberate.** Momentum matters less; precision matters more.

---

## Zones

Green Hill, Bridge, Jungle, Labyrinth, Scrap Brain, Sky Base — three acts each, Robotnik at the end of the third.

**Labyrinth** is the underwater zone with the air countdown, and it is the least popular here as everywhere.

**Sky Base** is the finale: electrified floors, wind, and a Robotnik fight with **no rings in the arena** — one hit ends it.

---

## Strategy

**Do not run blindly.** Even with the larger screen, this game places hazards where speed cannot save you. Walk unfamiliar ground.

**Hold at least one ring.** One ring means you survive a hit; zero means death. Detouring for a single ring before a boss is correct.

**The Emeralds are worth it** if you want the real ending, and they are genuinely hidden — expect to explore off-route.

## Emulation Notes

Runs perfectly on Batocera's Master System core, **rewind enabled**.

If you own both, play this one rather than the Game Gear version — identical content, meaningfully more visible playfield. The Game Gear release is worth keeping only for portability, which is not a consideration here.

The ROM is `Sonic The Hedgehog (USA, Europe, Brazil)`. Brazil is in the region list because Tectoy kept the Master System alive there for decades after it died elsewhere.
